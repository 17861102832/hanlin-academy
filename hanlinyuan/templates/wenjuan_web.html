⚙️关于《翰林·修文卷》

为什么做它：英语研究课上老师说"论文期刊格式，Agent 做不了"——不服，于是从 GitHub 抓取清华 THUDM 官方 Agent 项目（AgentBench / AgentTuning / LongWriter / LongCite 等）与全球高分学术写作技能包，融合 DeepSeek Harness 的插件化思路与视觉皮肤，组装成这台离线的期刊格式修复学术 Agent。
核心能力：① 变形文本修复（断行/连字/水印/全角标点）；② 参考文献自动拆条+斜体规范+悬挂缩进+APA/国标/MLA 三式转换；③ 一键导出 WPS/Word 直开的 .doc（Times New Roman、双倍行距、悬挂缩进全套样式）；④ 内置 30+ 权威学术 Agent 技能指纹；⑤ 可选 DeepSeek API 联网润色。
零依赖：单文件 HTML，双击即用，数据不出本机。
